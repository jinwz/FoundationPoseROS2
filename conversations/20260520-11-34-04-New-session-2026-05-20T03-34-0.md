### 3. Main Entry Point / Launch File

**File**: `/home/jinwz/FoundationPoseROS2/FoundationPoseROS2/foundationpose_ros_multi.py`

This is the sole ROS2 node. It is NOT a standard ROS2 package with `setup.py`/`package.xml`/launch files. It is a standalone Python script that:

- Creates a ROS2 node called `pose_estimation_node` using `rclpy`
- Subscribes to:
  - `/camera/camera/color/image_raw` (RGB images)
  - `/camera/camera/aligned_depth_to_color/image_raw` (aligned depth images)
  - `/camera/camera/color/camera_info` (camera intrinsics)
- Publishes `PoseStamped` messages to `/Current_OBJ_position_1`, `/Current_OBJ_position_2`, etc. for each tracked object
- Uses a Tkinter GUI (`FileSelectorGUI`) at startup for selecting/reordering object mesh files
- Uses OpenCV + SAM2 (`ultralytics.SAM("sam2.1_b.pt")`) for interactive segmentation
- Uses FoundationPose libraries (`estimater.py`, `ScorePredictor`, `PoseRefinePredictor`, etc.)

There is **no ROS2 launch file** (no `.launch.py` anywhere). The Dockerfile references `python3 main.py` which does not exist in the repo -- the actual file is `foundationpose_ros_multi.py`.

### 3. Main Entry Point / Launch File

**File**: `/home/jinwz/FoundationPoseROS2/FoundationPoseROS2/foundationpose_ros_multi.py`

This is the sole ROS2 node. It is NOT a standard ROS2 package with `setup.py`/`package.xml`/launch files. It is a standalone Python script that:

- Creates a ROS2 node called `pose_estimation_node` using `rclpy`
- Subscribes to:
  - `/camera/camera/color/image_raw` (RGB images)
  - `/camera/camera/aligned_depth_to_color/image_raw` (aligned depth images)

- Uses FoundationPose libraries (`estimater.py`, `ScorePredictor`, `PoseRefinePredictor`, etc.)

There is **no ROS2 launch file** (no `.launch.py` anywhere). The Dockerfile references `python3 main.py` which does not exist in the repo -- the actual file is `foundationpose_ros_multi.py`.
