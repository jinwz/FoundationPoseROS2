## 2. README FILES AND DOCUMENTATION

### Top-level `/home/jinwz/FoundationPoseROS2/FoundationPoseROS2/README.md`

- **Title:** FoundationPoseROS2: Multi-Object Pose Estimation and Tracking of Novel Objects in ROS2 with RealSense2
- **Author:** Ammar N. Abbas
- **Purpose:** A ROS2-integrated system for 6D object pose estimation and tracking, based on FoundationPose + SAM2 segmentation + RealSense2 camera
- **Key features:**
  - ROS2-based real-time framework (works with 8GB GPU)
  - SAM2-based automatic segmentation
  - Multi-object pose estimation and tracking
  - Interactive GUI for object model-to-mask assignment
- **Prerequisites:** Ubuntu 20/22, ROS2 Foxy/Humble, 8GB+ NVIDIA GPU, CUDA 12.x, Intel RealSense camera
- **Instructions provided for:** conda env setup, building extensions, running with live camera, running with rosbag2, and running on novel objects
